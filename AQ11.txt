Experiment 11: Ansible Playbook – File + Service (Idempotency) (Enhanced)
Problem Statement:
Write an Ansible playbook that creates a file and ensures nginx is installed and running. Run the playbook twice to show idempotency.
Prerequisites:
•	Ansible inventory ready
•	Ubuntu/Debian target (apt available)
Procedure:
1.	Create playbook.yml with file + package + service tasks
2.	Run playbook and verify results
3.	Re-run playbook and show minimal changes
Solution / Files / Commands:
playbook.yml:
- name: Copy file and start nginx
  hosts: servers
  become: yes

  tasks:
    - name: Create file in /tmp
      copy:
        content: "DevOps Exam File"
        dest: /tmp/exam.txt

    - name: Ensure nginx installed
      apt:
        name: nginx
        state: present
        update_cache: yes

    - name: Ensure nginx is running
      service:
        name: nginx
        state: started
Run Commands:
ansible-playbook -i inventory.ini playbook.yml
ansible-playbook -i inventory.ini playbook.yml
Expected Output / Verification:
First run shows changes; second run shows mostly ok (idempotent)
